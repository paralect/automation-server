# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting (the "Report a vulnerability" button on the repository's Security tab). Include steps to reproduce and the affected version or commit.

You can expect an acknowledgement within a few days. Fixes are released as soon as practical and credited unless you prefer otherwise.

## Scope

This server receives webhooks from the internet and holds third-party tokens. Reports about signature verification, request handling, secret leakage in logs or outputs, and dependency vulnerabilities are in scope.
